# 齿间 · 一口好牙自助指南

> 面向普通人的口腔健康科普与自检网站。把牙医的「牙位语言」翻译成大家看得懂、用得上的工具。
> 口腔医学专业学生作品 · 黑客松项目。

🔗 在线体验：https://aaaaaliangjiayu.github.io/oral-care-atlas/

---

## 为什么做这个

身边的人看牙，常常「不知道自己哪颗牙出过问题、补过几颗、智齿长歪没有」，
而医生用的 FDI 牙位编号、萌出时间对这些普通人来说完全是天书。
作为口腔医学专业的学生，我想把课堂上学到的牙位系统、萌出规律、常见牙病防治，
做成一个普通人也能自助使用的网站——**看牙之前先懂一点自己的牙**。

## 核心功能

| 模块 | 做什么 | 亮点 |
|---|---|---|
| 🦷 牙齿自测 | 点交互式牙弓图上的任意一颗牙，看它的分工、常见问题、护理要点，并做症状自检 | 自绘 SVG 牙弓，标签沿牙弓径向排布避免重叠；按症状数量给出「观察 / 就医」分级建议 |
| 📋 我的牙位档案 | 选「画笔」（龋齿/已补/牙冠/缺失/阻生）点牙标记，生成个人牙位档案并导出 | 基于开源组件 `react-odontogram` 二次开发，叠加多状态着色 + 逐个标记 + 文本导出 |
| 📈 换牙时间线 | 拖动「年龄尺」，看某个年龄应有的乳牙/恒牙萌出情况 | 把月龄数据折算成年龄，当前年龄段高亮，家长与学生都能用 |
| ⏱ 刷牙教练 | 2 分钟四象限分区计时 + 21 天打卡 | 按巴氏刷牙法把 2 分钟切成 8 段，逐区引导，刷完自动打卡 |

## 开源融合（本项目重点）

这不是从零造的轮子，而是**在多个成熟开源项目基础上，围绕口腔医学场景做的裁剪、改造与融合**：

- **[react-odontogram](https://github.com/biomathcode/react-odontogram)**（MIT）——牙位图核心组件。
  直接复用其 FDI 编号、多牙列、条件着色能力，在其之上实现了「画笔式逐个标记 + 档案概览 + 文本导出」的原创交互。
- **刷牙计时器类项目**（如 toothbrush-timer 等）的 2 分钟概念 → 我改造为**巴氏刷牙法分区引导 + 21 天习惯打卡**。
- **牙科科普知识库类项目**的内容组织思路 → 我重新按 FDI 牙位体系与萌出规律整理了结构化数据（`src/data/dentalInfo.js`）。

详细的第三方清单与许可见 [`ATTRIBUTIONS.md`](./ATTRIBUTIONS.md)。

## 技术栈

React 19 · Vite 8 · Tailwind CSS v4 · react-odontogram · 纯前端（无需后端，构建即用）

## 本地运行

```bash
npm install
npm run dev      # 开发
npm run build    # 生产构建，产物在 dist/
```

## 自动部署（GitHub Pages）

仓库已配置 `.github/workflows/deploy.yml`：每次 push 到 `main` 会自动构建并发布到 GitHub Pages。
首次需在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**（之后无需再管）。
上线地址即本 README 顶部的在线体验链接。
